✅ Entry Logic (5m Timeframe)
   └─ WAIT_SWEEP: Liquidity sweep detection
   └─ WAIT_DISPLACEMENT: Strong directional move
   └─ WAIT_RETRACE: Pullback after displacement
   └─ WAIT_CONFIRM: Confirmation candle
   └─ OPEN: Position opened at close price

✅ Structural Stop Loss
   └─ LONG: Below swing_low + 0.02% buffer
   └─ SHORT: Above swing_high + 0.02% buffer
   └─ Minimum 0.3% distance enforced

✅ Structural Take Profit
   └─ TP1: First swing ahead (internal liquidity)
   └─ TP2: Second/major swing ahead (external liquidity)

✅ Exit Logic
   └─ SL hit → Close position at SL price
   └─ TP1 hit → Move SL to breakeven, continue
   └─ TP2 hit → Close position fully

ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════

Main Components:
├── Exchange Integration (CCXT Binance)
├── Data Fetching (OHLCV for 30m & 5m)
├── Swing Detection (Fractal LR=2)
├── Bias Detection (BOS/CHoCH)
├── Entry State Machine (4 states)
├── Position Management (Paper trading)
├── Exit Logic (SL/TP1/TP2)
└── Logging (Console & CSV)

State Flow:
WAIT_SWEEP → WAIT_DISPLACEMENT → WAIT_RETRACE → WAIT_CONFIRM → OPEN

Position Management:
Entry → Monitor → TP1 (move SL to BE) → TP2 (close) or SL (close)
