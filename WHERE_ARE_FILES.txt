🇮🇹 ITALIANO:

1. Il file CSV è salvato NELLA STESSA CARTELLA del bot
2. Nome file: ict_trades.csv
3. Esempio:
   
   Se il bot è qui:     C:\Users\Marco\bot\ict_bot_minimal.py
   Il CSV sarà qui:     C:\Users\Marco\bot\ict_trades.csv

Come trovarlo:
   Windows → Apri la cartella del bot → Cerca "ict_trades.csv"
   Linux/Mac → Usa comando: ls ict_trades.csv

🇬🇧 ENGLISH:

1. CSV file is saved in the SAME FOLDER as the bot
2. File name: ict_trades.csv
3. Example:
   
   If bot is at:        C:\Users\John\bot\ict_bot_minimal.py
   CSV will be at:      C:\Users\John\bot\ict_trades.csv

How to find it:
   Windows → Open bot folder → Look for "ict_trades.csv"
   Linux/Mac → Use command: ls ict_trades.csv
